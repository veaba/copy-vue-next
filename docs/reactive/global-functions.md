# 全局函数

| 全局定义         | 作用                                               |
|--------------|--------------------------------------------------|
| `startBatch` |                                                  |
| `endBatch`   |                                                  |
| `toRef`      | 入参是函数，同时是`isRef` 和 `isReadonly`；入参是蠢对象，仅 `isRef` |
| `toValue`    | 规范ref、computed，函数、纯数值等输出                         |

## startBatch 函数

批量深度，`batchDepth++`

## endBatch 函数

执行复杂的批处理计算属性操作。

- 有批处理深度，直接返回
- 重置批处理计算属性
- 处理活跃的订阅者，触发更新订阅者：`trigger()`

## toRef 函数

针对四种入参类型处理：

- `ref`
- `function`
- `object`
- `其他`

## toRefs 函数

对响应式对象每个属性进行一次 `toRefs`，并维持响应式的同时解构。

- 必须是响应式对象，纯对象无法处理
- 必须是响应式对象，纯数组无法处理，内部有判断函数 `isProxy()`，也就是判断 `___v_raw` 属性
